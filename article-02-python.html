💬 なぜPythonを使うことになったのか

職場のエンジニアに言われた。「Excelマクロは止めて、Python使いません？」

「えーーー、無理！！！」

Pythonって、エンジニアが使うやつでしょ。私には関係ない話だと思っていた。

でも違った。勉強はゼロでよかった。VBAコードをChatGPTに渡してPythonに変換してもらっただけ。コードの意味は1ミリもわからない。でも動いた。

🔧 準備：Pythonのインストール（約10分）

まず1回だけ、パソコンにPythonを入れます。入れてしまえばあとは何度でも使えます。

  1. https://www.python.org/downloads/ にアクセスする
  2. 一番上の安定版をクリック（ページ中央の大きな黄色ボタンは押さない）
  3. インストーラーが開いたら ⚠️「Add Python to PATH」に必ずチェック を入れてから「Install Now」を押す
  4. インストール確認：Windowsキー+R → 「cmd」と入力してEnter → python --version と入力してEnter
⚠️ 重要：PATHのチェックを忘れると 「Add Python to PATH」にチェックを入れ忘れると、batファイルをダブルクリックしても黒い画面が一瞬出て消えるだけになります。そうなったらPythonをアンインストールして入れ直すのが一番早いです。

openpyxlの追加インストール

Pythonのインストールが終わったら、ExcelファイルをPythonで読み書きするためのパッケージを追加します。コマンドプロンプトに以下を貼り付けてEnter。

pip install openpyxl

「Successfully installed openpyxl-3.1.5」のような表示が出ればOKです。

第1章：VBAコードをそのまま渡すだけ。全プロンプト公開

ChatGPTに渡したのは2つだけ。自分で作っていた引き継ぎ書（Excel）と、VBAコードです。

難しいことは何もしていない。持っているものをそのまま渡しただけ。

🔑 VBAコードがある人向け

プロンプトテンプレート ①-A
以下の2つを添付します。 ・手順書（①〇〇 ②〇〇 というシート名） ・VBAコード 中身を確認してPythonコードを作ってください。 不明点があれば先に質問してください。

ポイントは最後の一言「不明点があれば先に質問してください」。これを入れると、的外れなコードを作られて「なんか違う」を繰り返す無駄がなくなります。

🔑 VBAコードがない人向け

プロンプトテンプレート ①-B
私はExcelで毎月こういう作業を手作業でやっています。 この作業を自動化するPythonコードを作ってください。 ■ 使っているファイル ・（例：アンケート結果のExcel。列はA〜Eで…） ■ やりたい処理（1ステップずつ） 1. 2. 3. ■ 私のスキル ・Excelは使えるがプログラミングは未経験 不明点があれば先に質問してください。

VBAがなくても大丈夫です。やっている作業を1ステップずつ書くだけで、ChatGPTが必要な情報を質問してくれます。

第2章：もらったコードを動かす（ダブルクリックで完結）

1 Pythonコードをメモ帳に保存する
  • ChatGPTのコードは「📄」ボタンでコピーする（マウスで範囲選択すると崩れることがある）
  • メモ帳を開いて貼り付ける
  • 「名前をつけて保存」を選ぶ
  • 「ファイルの種類」を必ず「すべてのファイル」に変更する
  • ファイル名：data_processing.py（.txtにならないよう注意）
  • 文字コード：UTF-8 を確認する
2 batファイルを作る
  • メモ帳を新規で開く
  • 以下のコードを貼り付ける
@echo off cd %~dp0 python data_processing.py pause
  • ファイル名：run.bat（ファイルの種類：すべてのファイル）
  • data_processing.py と同じフォルダに保存する

batファイルもChatGPTに作ってもらえます。

プロンプトテンプレート ②
作ってもらったPythonコードを ダブルクリックだけで実行できるように batファイルも作ってください。
3 ダブルクリックで動かす
  • 処理対象のExcelファイルを data_processing.py と同じフォルダに入れる
  • run.bat をダブルクリックする
  • 「完了しました」と表示されれば成功

よくあるエラーと対処

  • 「data.xlsxが見つかりません」 → ExcelファイルをPythonファイルと同じフォルダに入れているか確認する
  • 黒い画面が一瞬出て消えた → PATHのチェックが入っていない可能性が高い。Pythonをアンインストールして入れ直す
  • 「ModuleNotFoundError: No module named ○○」 → コマンドプロンプトで pip install ○○ を実行する

第3章：GitHubへの上げ方（コピペするだけの早見表）

⚠️ GitHubは「必須」ではありません 第2章までで自動化は完成しています。GitHubは「別PCでも使いたい」「職場に配りたい」「バックアップを取りたい」ときだけ使います。

会社で使う場合の3つの確認

  • 会社が外部サービスへのコード保存を許可しているか
  • リポジトリは必ず「Private（非公開）」にする
  • 取引先名・個人情報はコードや手順書に書かない

コピペ用：GitHubに上げるときの呪文4ステップ

【①フォルダに移動する】 cd C:\Users\あなたのユーザー名\Desktop\my_project 【②変更したファイルを準備する】 git add . 【③変更内容を保存する】 git commit -m "更新" 【④GitHubにアップロードする】 git push

この4ステップをそのままメモ帳に保存しておくと、毎回コピペするだけで済みます。

この早見表もChatGPTに作ってもらえます。

プロンプトテンプレート ③
GitHubにコードを上げるときに必要な呪文を 毎回コピペするだけで使えるように 最初のフォルダ指定から全部含めて 早見表にまとめてください。 リポジトリはPrivate（非公開）で作る前提でお願いします。

第4章：職場の誰でも使える手順書の作り方

コードを作ったら、一緒に手順書も作ってもらいましょう。「後任者が来たとき」「しばらく使わなくて忘れたとき」に役立ちます。

プロンプトテンプレート ④
ノンエンジニアでもわかりやすい手順書を GitHubに登録するmdファイルを作ってください。
💡 形式を指定するのがポイント 「ノンエンジニアでもわかりやすい手順書を作って」だけだとカラフルで絵文字まみれのものが返ってきます。「mdファイルを作って」と形式を指定するとシンプルなものができます。

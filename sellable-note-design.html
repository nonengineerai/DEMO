Note Design Framework

売れるnoteの設計書

「情報」を売るな。「読み終わった後の未来」を売れ。

Core Philosophy
根本思想
有料noteが売れる理由は、情報の量でも質でもない。
有料noteは 「読み終わった後の未来」 を売っている。
情報を売っているわけではない。
だから設計で最初に決めるのは「誰に」「何を解決するか」「どんな未来を見せるか」の3点だけ。
未来が見えないと、人は動かない。
🎯
誰に向けるか
ターゲット読者を1人に絞る。全員向けは誰にも刺さらない。
🔧
何を解決するか
読者が今抱えている具体的な悩み・摩擦・停滞を1つ特定する。
🔮
どんな未来を見せるか
読後に「自分の生活がこう変わる」と想像できる状態を設計する。
Persona × Value Map
10の読者ペルソナ × 訴求軸
読者タイプを見極め、「何を見せるか」を切り替える。
01
初心者
再現性を見せる
"自分にもできそう" を作る
02
発信者・クリエイター
効率化を見せる
時短・自動化はかなり強い
03
副業層
収益性を見せる
"いくら狙えるか" を具体化する
04
不安が強い人
安全性を見せる
失敗しにくさを伝える
05
行動できない人
具体性を見せる
手順・型・テンプレを出す
06
情報収集好き
網羅性を見せる
"これ1つで完結" を作る
07
経験者・中級者
独自視点を見せる
他にない考え方を入れる
08
本気層・意識高い系
未来を見せる
"生活変わるかも" を想像させる
09
忙しい人
即効性を見せる
"今日から使える" を作る
10
比較検討している人
信頼性を見せる
実績・数字・体験談を入れる
使い方のポイント： ターゲット読者が「どのペルソナに近いか」を先に決めてから、タイトル・冒頭・目次の訴求軸を1本に絞る。 複数ペルソナを同時に狙うと軸がブレ、誰にも刺さらないnoteになる。
Design Sheet
note設計シート（記入テンプレ）
執筆前にこの3問に答えるだけで、売れる構造が決まる。
SELLABLE NOTE — DESIGN TEMPLATE
01 — ターゲット設計
読者ペルソナ
上の10タイプから1つ選択 → 「〇〇な人」と1行で書く
今の状態
読者が今感じている悩み・不満・停滞を具体的に記述
訴求軸
再現性 / 効率化 / 収益性 / 安全性 / 具体性 / 網羅性 / 独自視点 / 未来 / 即効性 / 信頼性
02 — 解決設計
解決する問題
読者が抱える1つの具体的な問題（欲張らず1つに絞る）
解決手段
手順 / テンプレ / 考え方 / 事例 / ノウハウ　※ペルソナに合わせる
差別化ポイント
無料記事・他noteと何が違うか。独自体験・数字・視点を1つ
03 — 未来設計（最重要）
「読み終わった後、読者の生活はどう変わっているか？」
ここが書けないnoteは売れない。
Before（今）→ After（読後）を具体的な行動・状態・数字で描く。
例：「毎日3時間かかっていた作業が30分で終わり、残りの時間で副業に集中できている」
Launch Checklist
公開前チェックリスト
設計がブレていないか最終確認。
✓
タイトルにペルソナと訴求軸が入っているか？（例：「副業初心者が3ヶ月で月5万稼いだ全手順」）
✓
冒頭300文字以内に「誰のためのnoteか」が明示されているか？
✓
冒頭に「読み終わった後どうなるか」の未来が書かれているか？
✓
目次を見ただけで「欲しい情報がある」と読者が判断できるか？
✓
信頼性要素（実績・数字・体験談）が最低1つ入っているか？
✓
サムネイルにペルソナか訴求軸のキーワードが視覚的に入っているか？
✓
価格は解決する問題の価値から逆算されているか？（コスト積算ではなく）
